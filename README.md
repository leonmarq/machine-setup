## How to dual boot
> [!NOTE]
> you need windows 11 preinstalled

1. disable Bitlocker: https://documentation.ubuntu.com/desktop/en/latest/how-to/turn-off-bitlocker-in-windows/#turn-off-bitlocker-in-windows 
2. Enable MS UEFI CA key: https://support.hp.com/us-en/document/ish_8680345-8679627-16
3. install linux from usb: https://linuxconfig.org/how-to-install-ubuntu-alongside-windows-11-dual-boot
4. resort grub bootmenu: https://ubuntuhandbook.org/index.php/2024/12/os-kernel-boot-default-ubuntu-linux/
