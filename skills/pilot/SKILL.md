---
name: pilot
description: Build one variant end to end before the rest. Use when a task spans several variants that each need their own real work, such as file formats, providers, integrations or expensive generation.
---

1. Pick the variant the user named, or else the one that matters most. Say which in one line.
2. Build it end to end and verify it works.
3. Stop, list the remaining variants, and ask before building them.

Skip this skill for mechanical repeats of a requested fix, and for anything a project requires for a feature to count as done: translations, supported platforms and parity rules.
